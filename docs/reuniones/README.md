# Actas de reuniones

Esta carpeta se reserva para las **reuniones realmente celebradas** por el equipo EvalHub. No contiene plantillas ni reuniones ficticias.

Al celebrar una reunión, copiar [`../plantillas/plantilla-acta.md`](../plantillas/plantilla-acta.md) y guardar el resultado como `AAAA-MM-DD-descripcion.md`. Verificar los asistentes, acuerdos y fechas antes de incorporarlo a `trunk`.

**Estado al 21/11/2026:** no se adjuntan aquí actas de reuniones verificadas.
